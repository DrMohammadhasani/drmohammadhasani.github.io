# Persian personal website — review draft

This is a static website ready for GitHub Pages. The supplied photo is unchanged; CSS controls the visible crop.

## Preview

Open index.html in a browser, or serve this directory with a local web server. The Persian font uses Google Fonts; the site falls back to Tahoma or Arial when it cannot load.

## Before publishing

- Confirm the Persian name and title with the family.
- Review the career summaries against the final CV. The blog contains differing dates and research descriptions. Education and selected role dates follow the English CV at /post/12 and are explicitly labelled as Gregorian years; confirm these before publication.
- Supply an approved downloadable CV and individual media links if desired. For now, the CV button opens the original CV post, and media cards open the blog archive.
- Add an approved professional contact email if desired. Home address, birth date, and unconfirmed phone/email details are omitted.

## Publish free with GitHub Pages

1. Use a GitHub account belonging to the family.
2. Create a public repository named USERNAME.github.io, replacing USERNAME with the exact account username.
3. Upload index.html, styles.css, script.js, .nojekyll, and the assets folder at the repository root. Do not upload the preview screenshots or README unless desired.
4. In repository Settings → Pages, choose Deploy from a branch, then main and / (root), and save.
5. The published address will be https://USERNAME.github.io/ once GitHub finishes deployment.

All site asset paths are relative, so a project repository at https://USERNAME.github.io/REPOSITORY/ also works. No build tools, backend, or paid hosting are needed.
